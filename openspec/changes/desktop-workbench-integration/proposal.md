# Desktop 工作台与侧边栏状态协作

## Why

原 F014 及 2026-10-14 工作流草案要求浏览参考资料时仍保留文档编辑目标。目前基础控制器与办公成员交付已有证据，但跨插件完整工作流仍未确认、未实现验收。本变更只迁移原需求，不授予实现权限。

## What Changes

- 明确当前文件、候选文件与工作台固定目标的独立职责。
- 保留路径围栏、会话隔离、队列确认和依赖权限门禁。
- 为 Desktop 多窗口、断线、冷启动与会议／项目联动建立验收条件。
- 不新增控制开关，不恢复旧客户端配置镜像，不接管文档节点、图像分析或语音引擎。

## Capabilities

### New Capabilities

- `desktop-workbench-integration`: F014 的工作台协作与多窗口状态契约。

### Modified Capabilities

无。现行控制能力保持；待确认增量不合入主规格。

## Impact

涉及控制器宿主服务、客户端桥接及工作台／文档插件联合验收。原草案目标 DSH 0.2.0-rc.2／Better Sidebar 0.25.0；2026-10-17 已兼容的新固定组合不自动改写该草案的批准状态。实施前需确认目标组合与本文档版本。
