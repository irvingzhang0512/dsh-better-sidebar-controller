# 文件树与目录控制

## Purpose

承接旧 F001、F003、F009 的当前行为，并按已确认 F011 统一权限和配置来源。控制器复用真实 Better Sidebar 文件树，让用户与 Agent 在工作区范围内列举和展开目录；本规格描述已落地行为，历史与本次验证范围分别见迁移索引。

## Requirements

### Requirement: F001 工作区列举与真实路径围栏

系统 SHALL 依据调用会话工作目录列举文件和目录，目录优先且名称排序稳定，返回名称、路径、目录、隐藏、符号链接、损坏链接及截断标志。目录控制和兼容打开 MUST 保持真实路径工作区围栏，处理符号链接及 WSL 映射；缺失、不可读或越界路径须结构化失败。

#### Scenario: 正常列举与越界拒绝
- **WHEN** 调用 list_files 省略路径或指定工作区目录
- **THEN** 返回合法目录的稳定单层条目；工作区外路径及越界链接被拒绝，缺失与读取失败可区分

### Requirement: F003 显隐与目录控制复用现有界面

系统 SHALL 提供显示、隐藏侧边栏、展开、折叠目录及刷新真实文件树的操作。全局可见性和展开状态作用于当前可见实例，不承诺每会话独立原生侧边栏，也不另建结构化节点树；相同展开指令 MUST 幂等。

#### Scenario: 目录展开及刷新
- **WHEN** 有效调用会话请求展开同一目录两次并刷新
- **THEN** 界面无重复展开状态，确认后状态与真实树一致；未连接时按排队规则反馈而非虚报完成

### Requirement: F009 列举配置默认及取值归一

系统 SHALL 保留 includeHiddenEntries（缺省 true）与 maxListedEntries（缺省 1000、最小 1）及既有存储键。数值非数字或非有限时回退 1000，有限小值夹为 1，分数取整；已设置的布尔值只有 true 表示开启。配置为全局偏好，由宿主读取有效所有者，不由客户端缓存授权。

#### Scenario: 默认与异常上限
- **WHEN** 配置缺省、上限为 3、0、负数、分数或非法值
- **THEN** 缺省返回隐藏项且上限 1000；合法 3 最多返回三行，有限小值夹到 1，非法数值回退 1000，结果不因异常崩溃

### Requirement: F009 先过滤再截断并保持配置

系统 SHALL 让 list_files 与 refresh_tree 共用单层列举规则，先过滤隐藏条目再应用行数上限，truncated 仅表示仍有符合条件的未返回条目。设置变化须在下一次调用生效，保存单字段 MUST 保留旧有效值、未知键和其他插件偏好。

#### Scenario: 隐藏项不占用配额
- **WHEN** includeHiddenEntries 为 false 且目录包含隐藏项与多个可见项
- **THEN** 隐藏项不返回且不占可见配额；只剩隐藏项时不标 truncated，标记与返回形状保持

#### Scenario: 设置持久与下一次调用
- **WHEN** 更改列举偏好后再次调用并刷新或重启
- **THEN** 有效值按同一所有者读取且保持；无客户端也不退回错误默认值，未知字段不丢失
