# dsh-better-sidebar-controller

**用自然语言让 Agent 打开文件、切换标签、整理文件树，操作你正在使用的侧边栏。**

这是 better-sidebar 的模型控制增强扩展。你说出任务，Agent 操作现有界面；鼠标和 Agent 的文件操作共享同一份状态。

## 能做什么

- 打开文件、文件夹窗口或网页，包括工作区外的绝对路径。
- 查询已打开文件，切换、关闭文件，或回到上一文件。
- 列举工作区目录，展开、折叠和刷新文件树。
- 显示或隐藏 DSH 官方右侧栏。

## 安装

本页对应插件 **0.3.0**，目标组合为 **DSH desktop 0.2.0-rc.2 + better-sidebar 0.25.0**。使用前必须安装并启用 better-sidebar 和本扩展。

**分发状态（2026-10-12）**：0.3.0 当前通过维护者提供的固定 `.tgz` 安装包安装，尚未提供可直接安装的 npm 包；[公开源码仓库](https://github.com/irvingzhang0512/dsh-better-sidebar-controller) 仍是旧版本。尚未安装的用户需先向维护者获取本版安装包与 desktop 安装说明，不能用公开仓库的旧版本替代。本机已经安装 0.3.0 的用户可直接进入下节配置。

安装完成后重启 DSH desktop，在 **设置 → 侧边卡片** 确认出现「Sidebar Controller 增强控制」卡片，再开启所需能力。

该组合已在隔离 desktop 宿主及真实浏览器客户端验证；Electron 原生窗口完整操作和真实模型自然语言链路仍待验收，详见 [验证记录](docs/VERIFICATION-0.3.0.md)。

## 配置

进入 **设置 → 侧边卡片**。第一次使用建议开启以下两个开关：

| 位置 | 开关 | 用途 |
|---|---|---|
| 常规 | 为模型注入侧边栏打开工具 | 让 Agent 打开文件、文件夹和网页 |
| Sidebar Controller 增强控制 → 功能设置 | 允许模型管理侧边栏 | 让 Agent 查询、切换和关闭文件，操作文件树及右侧栏显示 |

两个开关未设置时均关闭，已有的打开开关值保留；**回到上一文件需要两个开关同时开启**。增强卡片会显示打开能力的关联状态，打开开关只需在「常规」设置一次。

设置自动保存，工具随开关变化更新。修改后发起新一轮对话核对；若当前会话工具列表尚未更新，可在新会话检查。关闭能力不会关闭已经打开的文件。

管理设置还可调整「列出隐藏项」（默认开启）和「单层条目上限」（默认 1000）。完整设置与生效检查见 [配置指南](docs/usage.md#配置)。

## 第一次使用

试着完成一次 **找文件 → 打开 → 确认 → 关闭**。先在 DSH 中进入你要操作的工作区会话，并开启上述两个开关。

1. 对 Agent 说：

   > 请使用 sidebar-controller 技能，检查打开和管理能力是否可用，然后列出当前工作区根目录的文件。

2. 从返回结果中选一个真实存在、可读的文件，把下面的路径换成它的实际路径，再说：

   > 在侧边栏打开 README.md，然后告诉我当前打开的是哪个文件。

   你应看到该文件的标签和内容，Agent 报告的当前文件路径应与它一致。文件显示在官方右侧栏还是底部工作台，沿用 better-sidebar 的设置。

3. 接着说：

   > 关闭当前文件，再告诉我还有哪些文件开着。

   刚打开的文件标签应关闭，查询结果中的已打开文件列表不再包含它。若界面自动切到其他文件，当前文件也会随之更新。

插件自带 `sidebar-controller` 技能，DSH 自动注册，无需手动复制或填写会话编号。技能可见不代表工具已经开启；遇到排队或超时，先按下文检查结果，再继续操作。

## 常用操作

| 想做什么 | 对 Agent 说 | 结果 |
|---|---|---|
| 查看文件状态 | “现在打开的是哪个文件？还有哪些文件开着？” | 返回当前、上一文件及已打开文件列表 |
| 切换文件 | “切到已经打开的 README.md” | 激活该文件标签；目标必须已经打开 |
| 返回上一文件 | “回到刚才那个文件” | 激活记录中的上一文件；需要两个开关 |
| 浏览文件夹 | “把 docs 文件夹作为一个窗口打开” | 打开独立文件夹浏览窗口；目录须存在 |
| 整理文件树 | “在文件树里展开 docs”／“刷新文件树” | 展开对应目录或重新读取目录内容 |
| 打开网页 | “在侧边栏打开 https://example.com” | 打开网页标签，加载情况取决于网站和网络 |
| 控制右侧栏 | “隐藏官方右侧栏”／“显示官方右侧栏” | 改变右侧栏显示状态，保留已打开文件 |

文件名和目录名使用实际存在的路径；不确定时先让 Agent 列目录。

## 使用边界

- 操作只作用于发出指令的会话。相对路径以该会话的工作目录为基准；要操作另一个会话，就在那个会话发出指令。
- 增强打开支持外部绝对路径；目录工具和旧兼容打开工具仍限制在工作区内。
- 网页、文件夹窗口和终端不计入当前／上一文件，本扩展也没有它们的关闭或历史导航工具。
- 显示／隐藏只控制 DSH 官方右侧栏；文件的展示位置沿用 better-sidebar 设置。
- 本插件操作界面。修改文件内容时，Agent 需要使用其他文件编辑工具。

## 常见问题

### 找不到增强设置卡，或 Agent 没有可用工具

先检查本扩展与 better-sidebar 是否安装、启用且版本匹配。卡片存在时再检查两个能力开关，并让 Agent 核对当前实际可用工具。仅开启管理可以操作已打开文件；打开新内容和返回上一文件仍需要打开开关。

### Agent 说已排队，但界面没有变化

`QUEUED` 表示等待调用会话的界面连接，操作尚未完成。回到发出指令的会话并等待连接恢复，避免重复发送同一操作。

### 操作确认超时，要重新打开吗

确认超时表示结果未知，操作可能已经发生。先查看界面或让 Agent 查询当前与已打开文件，再决定是否重试。
